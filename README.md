# ダブルス交流大会 抽選・得点管理アプリ

ダブルス形式の交流大会（バドミントン、テニス等）向けの対戦組み合わせ抽選＆得点管理ツールです。「毎回違う相手と組んで、いろんな人と交流できる」ことを目標に、ペアや対戦相手の重複を自動で避けながら抽選します。

## オンラインデモ

以下のURLからブラウザ上ですぐに試せます（インストール不要）。

https://yumeno.github.io/Single_Entry_Doubles_System/

## 特徴

- **スマート抽選**: 初回は完全ランダム、2回目以降は過去の履歴を考慮して重複を最小化
- **途中参加・離脱対応**: 大会途中でのメンバー増減にも柔軟に対応
- **得点管理**: ラウンド数の入力だけで自動集計・ランキング生成
- **大会設定**: 大会名・開催日を設定してヘッダーに表示
- **データ保存・読込**: 全データをJSONファイルに保存・復元可能（ブラウザリロードしても安心）
- **完全オフライン**: サーバー不要、HTMLファイル1つで完結
- **マルチ環境対応**: GitHub Pages、ローカルPC、スマートフォンすべてで動作

## 導入方法

### 方法1: オンラインで使う

https://yumeno.github.io/Single_Entry_Doubles_System/ にアクセスするだけで利用できます。

### 方法2: ダウンロードしてローカルで使う

1. [リリースページ](https://github.com/Yumeno/Single_Entry_Doubles_System/releases) から最新の `doubles_tournament_X.X.X.zip` をダウンロード
2. zipを展開し、`index.html` をダブルクリックで開く（ブラウザが起動します）

### 方法3: GitHub Pagesで自分用に公開

1. このリポジトリをフォーク
2. Settings → Pages → Source を「main」ブランチに設定
3. 数分後に `https://ユーザー名.github.io/Single_Entry_Doubles_System/` でアクセス可能

## 使い方

### 1. メンバーを登録する

1. 右上の ☰ メニューから「**メンバー管理**」を開く
2. テキストエリアに参加者名を1行1名で入力
3. 「反映」ボタンを押す

初期状態ではサンプルの8名が登録されています。

### 2. 抽選する

1. 「**抽選**」ボタンを押す
2. 候補が表示される（対戦カード、ペア一覧、スコア内訳など）
3. 気に入らなければ再度「抽選」を押すと別の候補が生成される
4. 「**確定**」ボタンで試合を確定する

#### 抽選のしくみ

- **第1試合**: 完全ランダムで組み合わせ
- **第2試合以降**: 過去の履歴を分析し、以下を自動で避けます
  - 同じ人とのペア再成立
  - 直前の試合と同じペア
  - 同じ対戦カードの再現
  - 同じ相手との対戦
  - 待機回数の偏り

候補表示には「新規ペア数」「ペア重複数」「対戦重複数」のサマリと、ペア重複がある場合は警告が表示されます。

### 3. 途中参加・途中離脱

- **途中参加**: ☰ →「メンバー管理」→ 下部の追加欄に名前を入力して「追加」
- **途中離脱**: ☰ →「参加状態の変更」→ 該当メンバーの「離脱」ボタン
- **復帰**: 同じ画面で「復帰」ボタン

休止中のメンバーは抽選対象外になりますが、履歴は保持されます。復帰後は過去の履歴を踏まえた抽選が行われます。

### 4. 得点を入力する

1. 確定済み試合の「**得点入力**」ボタンを押す
2. 各対戦カードの両チームの**取得ラウンド数**を入力
3. ラウンド数が多い方に自動で「WIN」が表示される
4. 必要に応じて各選手の**ボーナス得点**を入力

入力は即座に保存されます（ダイアログを閉じても消えません）。

### 5. ランキングを確認する

1. 上部の「**ランキング**」タブをクリック
2. 全メンバーの得点集計が表示される

#### ランキングの操作

- **表示切り替え**: 「累計」または「第n試合」をドロップダウンで選択
- **ソート**: 列ヘッダーをクリックで並び替え（降順 → 昇順 → 登録順 の3段階）
- **得点内訳**: 各メンバーの「勝利点 + ラウンド点 + ボーナス」の内訳を表示

#### 得点の計算式

```
個人得点 = 勝利数 × 勝利得点 + 総ラウンド数 × ラウンド得点 + ボーナス得点
```

初期設定では「1勝 = 0点」「1ラウンド = 1点」です。つまりデフォルトでは取得ラウンド数の合計がそのまま得点になります。

### 6. 大会名・開催日を設定する

1. ☰ →「**大会設定**」を開く
2. 大会名と開催日を入力して「反映」
3. ヘッダー直下に大会名と開催日が表示される

### 7. 試合情報をコピーする

各確定済み試合の「**コピー**」ボタンを押すと、対戦カード・ペア・スコア等がテキスト形式でクリップボードにコピーされます。LINEグループへの共有などに使えます。

### 8. データを保存・読み込む

#### データ保存

☰ →「**データ保存**」で、大会の全データ（大会情報、メンバー、試合履歴、得点、設定値すべて）をJSONファイルとしてダウンロードできます。ファイル名には大会名と開催日が含まれます。

#### データ読込

☰ →「**データ読込**」で、保存したJSONファイルを選択して全データを復元できます。途中でブラウザを閉じても、保存さえしておけば続きから再開できます。

### 9. 履歴を確認する

#### ペア回数マトリクス

☰ →「ペア回数マトリクス」で、誰と誰が何回ペアを組んだかをマトリクス表示します。回数が多いセルほど濃い赤で表示されるヒートマップです。

#### 敵対回数マトリクス

☰ →「敵対回数マトリクス」で、誰と誰が何回対戦したかを同様に表示します。

## 設定のカスタマイズ

### 得点配分の変更

☰ →「**得点配分設定**」で以下を変更できます。

| 設定 | 初期値 | 説明 |
|------|--------|------|
| 1勝あたりの得点 | 0 | 勝利ごとに加算される点数 |
| 1Rあたりの得点 | 1 | 取得ラウンド1つにつき加算される点数 |

例: 「勝利重視」にしたい場合は、勝利得点を10、ラウンド得点を1に設定します。

### 抽選スコアの調整

☰ →「**抽選スコア設定**」で、抽選アルゴリズムの重みを細かく調整できます。通常は初期値のままで問題ありませんが、以下のような調整が可能です。

| やりたいこと | 調整する設定 |
|-------------|-------------|
| ペア重複をもっと厳しく避けたい | 「ペア重複ペナルティ」を増やす |
| 待機の偏りを減らしたい | 「待機偏りペナルティ」を増やす |
| 抽選の精度を上げたい（計算に時間がかかる） | 「探索回数」を増やす |
| 同じ対戦カードの再現を避けたい | 「同一カード重複ペナルティ」を増やす |

## リセット

### 履歴リセット

☰ →「履歴リセット」で、試合履歴と得点データのみをクリアします。メンバー登録と参加状態はそのまま残ります。

### 全リセット

☰ →「全リセット」で、すべてを初期状態に戻します。

いずれも確認ダイアログが表示され、誤操作を防止します。

---

## 注意事項

- ブラウザをリロードするとメモリ上のデータは消えます。大会中はこまめに「**データ保存**」でJSONファイルを保存してください
- 保存したJSONファイルがあれば「**データ読込**」でいつでも復元できます
- 推奨ブラウザ: Chrome, Safari, Firefox, Edge（最新版）
- 人数が4の倍数でない場合、余りの人数分だけ待機者が出ます（待機回数が均等になるよう自動調整）
